# CMPE 188 Project – Group 13

## Project Overview

This project uses the **Pima Indians Diabetes** dataset to build and evaluate machine learning models for diabetes prediction.

## Dataset

**Dataset:** Pima Indians Diabetes

**Training data:** `pima_diabetes_train.csv`

The dataset contains **652 rows and 9 columns**.

### Features

- `pregnancies`
- `glucose`
- `blood_pressure`
- `skin_thickness`
- `insulin`
- `bmi`
- `diabetes_pedigree`
- `age`

### Target

`outcome`

Possible values:

- `tested_negative`
- `tested_positive`
